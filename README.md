# SG Hub

AI 驱动的学术文献管理桌面应用 · 本地优先 · 隐私可控

## 下载

前往 [Releases](https://github.com/zmc0081/SGHUB-Release/releases/latest) 下载最新版：

- **Windows**：`SG.Hub_x.x.x_x64-setup.exe`
- **macOS**：`SG.Hub_x.x.x_x64.dmg`

系统要求：Windows 10 21H2+ / macOS 12+

> Windows 首次运行如提示 SmartScreen，点击"更多信息 → 仍要运行"。

## 主要功能

- 多源聚合检索（arXiv / PubMed / Semantic Scholar / OpenAlex / Crossref / CORE / DBLP / DOAJ）
- 文献数据库管理、本地 PDF 集中管理
- 内置 PDF 阅读器、划线高亮标注、全文翻译
- AI 文献精读解析（多 Skill）
- Chat 自由对话（附件 / Skill / 多模型）
- 模型配置（BYOK：Claude / GPT / Gemini / DeepSeek / 本地 Ollama）

## 隐私

- 文献、PDF、标注、Chat 内容全部存储在本地，不会上传
- BYOK 模式请求直连模型提供商，不经任何 SG Hub 服务器
- API Key 存储在操作系统密钥链
